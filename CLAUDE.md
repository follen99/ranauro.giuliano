# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Static personal portfolio site for Giuliano Ranauro, deployed on GitHub Pages. No build tools, no npm/node dependencies — everything is plain HTML/CSS/JS, with `marked.js` pulled from a CDN (cdnjs) for Markdown rendering.

## Commands

Serve locally to test (no build step required):

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. There is no linter, test suite, or build/deploy pipeline in this repo — deployment is just pushing to the branch GitHub Pages serves from.

## Architecture

- `index.html` — the homepage. It is a single self-contained file (inline `<style>` and `<script>`, no external JS files). The project grid is **not** generated by scanning the filesystem at runtime; it's driven by a hardcoded `PROJECTS` array inside the `<script>` block near the bottom of the file (search for `const PROJECTS = [`). Each entry needs `slug` (must match the folder name under `projects/`), `name`, `tag`, `desc`, and an `accent` hex color used for the card's tag styling.
- `projects/<slug>/index.html` — every project page is a copy of `projects/project-template/index.html`, unmodified. This template fetches `./README.md` at runtime via `fetch()` and renders it client-side with `marked.js`. It also rewrites the page `<title>` and a topbar filename label based on the URL slug. Because rendering happens via `fetch`, project pages must be served over HTTP (not opened as `file://`) to work.
- `projects/<slug>/README.md` — the actual content shown on each project page. Supports full GFM (tables, code fences, images). Relative image paths resolve against the project folder, so images referenced in a README must live alongside it (e.g. `projects/vending-locator/screenshot.png`).
- `resources/` — shared favicon/icon assets referenced from the site (not per-project).

### Adding a new project

1. Create `projects/<slug>/`.
2. Copy `projects/project-template/index.html` into it verbatim.
3. Write `projects/<slug>/README.md` with the project's content (and any images in the same folder).
4. Add a matching entry to the `PROJECTS` array in `index.html` (slug must match the folder name exactly, or the card link breaks).

There is no other wiring — no manifest file, no build step regenerates anything.

### Styling conventions

All pages share the same design system defined via CSS custom properties in each file's own `:root` block (`--bg`, `--accent`, `--accent2`, `--accent3`, `--text`, `--muted`, fonts `Syne` for headings and `DM Mono` for body/mono text, loaded from Google Fonts). Since there's no shared stylesheet, changing the visual theme means editing the `:root` variables in `index.html` and `projects/project-template/index.html` consistently (existing project pages already copied from the template will need the same edit applied individually if the theme should change site-wide).
